# e-Booking Domestic Profile

Modern Angular 22 standalone dashboard for the e-Booking Domestic customer profile screen.

## Run Locally

```bash
npm install
ng serve
```

Then open `http://localhost:4200/`.

If Windows PowerShell blocks `ng.ps1`, run either:

```bash
ng.cmd serve
```

or:

```bash
npm start
```

## Stack

- Angular 22 standalone components
- Angular signals and computed state
- Strongly typed reactive forms
- Zoneless change detection
- Tailwind CSS
