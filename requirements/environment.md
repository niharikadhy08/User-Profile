# Environment

Recommended local setup:

- Node.js 24.x or newer compatible LTS/current runtime
- npm 11.x
- Angular CLI 22.0.4

Install dependencies:

```bash
npm install
```

Run the app:

```bash
ng serve
```

Windows PowerShell note:

If script execution policy blocks `ng` or `npm`, use the `.cmd` executable:

```bash
npm.cmd install
ng.cmd serve
```
